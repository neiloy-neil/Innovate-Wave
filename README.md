# Innovate Wave - Creative Agency Website

A modern, responsive website for Innovate Wave creative agency built with TypeScript and React.

## Project Overview

This project is a complete website for Innovate Wave, a premium creative agency based in Bangladesh. The website showcases creative services, portfolio, team members, and contact information with a professional, modern design.

## Features

- Responsive design using Tailwind CSS
- Modular component architecture
- TypeScript for type safety
- SEO optimized
- Modern UI/UX design with oceanic theme

## Pages

1. **Homepage** - Main landing page with hero section, services overview, creative content, and testimonials
2. **About Us** - Company story, mission/vision, and leadership profiles
3. **Services** - Detailed listing of all creative services offered
4. **Portfolio** - Showcase of past work with filtering capabilities
5. **Contact** - Contact form and company information

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **Build Tool**: Vite
- **Animation**: Framer Motion
- **Package Manager**: npm

## Folder Structure

```
src/
├── assets/          # Images and static assets
├── components/      # Reusable UI components
├── data/            # TypeScript interfaces and mock data
├── hooks/           # Custom React hooks
├── layouts/         # Page layouts
├── pages/           # Page components
├── sections/        # Section components for pages
├── styles/          # Global styles
└── utils/           # Utility functions
```

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm run dev
   ```

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build

## Deployment

### Vercel Deployment

This project is configured for easy deployment to Vercel:

1. Push your code to a GitHub repository
2. Log in to your Vercel account
3. Click "New Project" and select your repository
4. Vercel will automatically detect the project settings
5. Click "Deploy" and your site will be live!

The `vercel.json` file is included to handle client-side routing.

## Development Guidelines
